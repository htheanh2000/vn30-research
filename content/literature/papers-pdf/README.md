## Khi Đọc, Ghi chú Theo Template

Cho mỗi paper, note lại:
1. **Họ dùng data gì?** (period, frequency, source)
2. **Method gì?** (có dùng cost-of-carry không? Nếu không, dùng gì?)
3. **Finding chính?** (1-2 câu)
4. **Gap so với bài bạn?** (họ KHÔNG làm gì mà bạn sẽ làm?)
5. **Cite được không?** (câu nào trong Introduction/Literature Review bạn sẽ cite?)
